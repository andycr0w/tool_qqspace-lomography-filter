# 拾光 LOMO

一个无后端、纯静态部署、在浏览器运行的怀旧照片滤镜工具。

视觉与成片效果参考 2010 年前后空间相册常见的 LOMO 风格。

了解更管有关Lomography的内容→ https://www.lomography.com/

## 功能

- 上传或拖放 JPG、PNG、WebP 图片
- 4 套 LOMO 配方：旧时光、青涩夏日、漏光日记、夜游人间
- 调整滤镜浓度、暗角和胶片颗粒
- 上传后自动应用滤镜，Slider 调整实时反馈到预览
- 手机竖屏使用底部滤镜抽屉，照片与控制项无需上下往返查找
- 可选照片日期戳
- 按住查看原图
- 按原图比例导出 PNG（为保证浏览器流畅度，最长边限制为 3200px）
- 图片全程只在浏览器内处理，不用担心作者偷你图片

## 运行

直接打开 `index.html`，或在本目录启动任意静态文件服务器。例如：

```powershell
python -m http.server 8080
```

然后访问 `http://localhost:8080`。
